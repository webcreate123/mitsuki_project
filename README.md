# MITSUKI MVP開発仕様書（Laravel開発版）

## 1. プロジェクト概要

### サービス名

MITSUKI

### 開発目的

「おためし転職」をコンセプトとした求人プラットフォームのMVP（最小実用版）開発。

奈良県での先行リリースを目的とし、企業が求人掲載を行い、求職者が簡単に応募できるシンプルな仕組みを構築する。

### リリース時期

2026年7月中旬

---

# 2. 開発方針

今回の開発では、ノーコードツールではなく Laravel を使用してシステム開発を行います。

理由として、今後の機能追加・サービス拡張・ユーザー増加を見据えた場合、Laravelによる開発の方が長期的な運用に適しているためです。

また、求人サイト・マッチングサイト系サービスにおいては、

* 会員管理
* 求人管理
* 権限制御
* 検索機能
* 管理画面
* API拡張

などが将来的に必要になるケースが多く、Laravelはそれらとの相性が非常に良いフレームワークとなります。

今回はご予算35万円という非常に限られた範囲ではありますが、単純なMVP制作ではなく、今後の拡張性を考慮した構成で開発を進めます。
